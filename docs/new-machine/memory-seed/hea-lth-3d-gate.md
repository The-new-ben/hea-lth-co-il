**CURRENT LIVE STATE (2026-07-13, release 9082548, theme+plugin 0.4.0):** the live model is **z-anatomy-layered-v2** — the full layered human BODY (skin-toned subcutaneous envelope + muscle-red musculature + bone-white skeleton) in one Draco asset pair (detail 6.8MB / mobile 1.4MB, 2.74M source tris, 946 meshes, names gate-normalized). 33 clickable structures = 19 skeletal + 14 Hebrew-labeled muscle groups; both system layers defaultVisible. Clicks pass through unmapped skin meshes to the muscle beneath (only structure-mapped meshes are pickable). Built via design-lab/3d-human-engine/pipeline/export_layered_figure_v2.py + generate_layered_manifest_v2.py per docs/runbooks/REAL_BODY_SWAP_RUNBOOK_2026-07-13.md; live-verified clicks (back-muscles/hamstrings). Gate gotchas learned: LOD ids must match `lod-[0-9]+`, a purpose="detail" LOD carries the ≥100k check, resolverEntityIds requires key `equipmentCategories` (not `services`) — one wrong key nulls the whole manifest → 'missing-manifest'. Face shows the muscular layer (atlas has no facial skin mesh); photoreal head = paid-asset path. Skeletal GLBs retained for rollback. Historical notes below.

The 3D human model on hea-lth.co.il is NOT broken — it is license-gated by design. three.js r185 is vendored in the theme (assets/vendor/three), the renderer is assets/js/anatomy-three-viewer.js, and the viewer shell exists in page-templates/template-anatomy.php. The front page shows a static teaser (front-page.php, section #body-discovery) until an approved model exists.

Unlock path: a manifest (schema in design-lab/3d-human-engine/) is stored as a WordPress option via the plugin settings page and must pass gate_manifest() in plugin-src/hea-lth-platform-core/includes/class-hea-lth-anatomy-model-registry.php (~line 555): status=approved; license.webDeliveryAllowed + derivativeUseAllowed + real owner + contractReference; clinicalReview approved with named owner + reviewedAt; gltfValid + visualQa/performanceQa/anatomicalFidelityQa/semanticMeshQa passed; a "detail" LOD ≥100,000 triangles; asset path same-origin HTTPS or root-relative.
